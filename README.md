# DAFAN-UNPACK v4.0

تطبيق Android محلي باسم **DAFAN-UNPACK**. يتضمن محرك Lua الذي أرسلته داخل التطبيق عبر Chaquopy، ويستدعيه التطبيق مباشرة عند اختيار أوامر فك وتجميع Lua؛ لا يحتاج المستخدم إلى فتح Termux لتشغيل العملية.

## وظائف Lua
- اختيار ملف Bytecode من مدير ملفات Android.
- فك تنسيق Lua المخصص الذي تنفذه أداة `nadeem.py` إلى مصدر Lua.
- تعديل المصدر النصي من محرر التطبيق.
- إعادة تجميع المصدر إلى تنسيق Bytecode المخصص مع الاستناد إلى الملف الأصلي.
- حفظ النتائج في مجلد يختاره المستخدم.

## بناء APK
يُبنى عبر GitHub Actions. سير العمل يقوم ببناء `luadec` و`luac5.3` من مشروع LuaDec مفتوح المصدر لـ Android arm64، ثم يضمّنهما داخل APK، ويضمّن Python runtime ومحرك المستخدم.

1. ارفع مجلد المشروع إلى مستودع GitHub باسم `DAFAN-UNPACK`.
2. افتح تبويب Actions.
3. شغّل `Build DAFAN-UNPACK APK` عبر Run workflow.
4. بعد نجاح البناء، نزّل artifact باسم `DAFAN-UNPACK-debug` وثبّت APK.

## توافق وحدود مهمة
- يتطلب Android 7.0/API 24 أو أحدث، ونسخة APK الحالية تستهدف `arm64-v8a`.
- محرك `DAFAN_LUA_ENGINE.py` يدعم فقط بنية Lua المخصصة التي تنفذها الأداة المصدرية `nadeem.py`؛ لا يعني ذلك دعم كل ملفات Lua أو كل تعديلات الألعاب.
- LuaDec يصف دعم Lua 5.2/5.3 بأنه تجريبي؛ قد يفشل مع ملفات مخصصة أو بايت كود غير مطابق.
- لا يوجد ادعاء بأن كل ملف سيفك أو يعاد تجميعه بنجاح. يجب اختبار الملف المستهدف، والاحتفاظ دائماً بنسخة أصلية.
- أدوات Lua الأصلية مرخصة بشكل مستقل؛ راجع مستودع LuaDec ومصدر Lua 5.3 قبل إعادة توزيع نسخ معدّلة.

## بقية ميزات المشروع
تحليل ELF/SO، استخراج أقسام ELF، قراءة ZIP/APK/JAR/OBB، واستخراج النصوص ASCII كما في المشروع السابق.
